Política de Privacidade

CineScope — Descoberta de Filmes

👋 Introdução

Esta Política de Privacidade descreve como o aplicativo CineScope coleta, usa e protege as informações dos seus usuários.

Ao usar o CineScope, você concorda com as práticas descritas neste documento. Se não concordar com algum ponto, recomendamos que não utilize o aplicativo.

📊 Dados Coletados

✅ O CineScope não coleta, armazena nem compartilha nenhum dado pessoal identificável dos usuários.

O aplicativo acessa apenas:

  • Informações públicas de filmes fornecidas pela API do TMDB (The Movie Database)
  • Dados de favoritos salvos localmente no seu dispositivo — nunca enviados a servidores externos

📱 Armazenamento Local

Os filmes marcados como favoritos são armazenados exclusivamente no seu dispositivo, utilizando um banco de dados local (Hive). Esses dados:

  • Nunca são enviados para servidores externos
  • Nunca são compartilhados com terceiros
  • São removidos automaticamente ao desinstalar o aplicativo
  • Podem ser apagados manualmente dentro do app

🌐 Acesso à Internet

O CineScope utiliza a internet exclusivamente para buscar informações de filmes (títulos, sinopses, imagens e avaliações) através da API pública do TMDB.

Nenhuma informação do usuário é enviada durante essas requisições. Para saber mais sobre as práticas de privacidade do TMDB, acesse: themoviedb.org/privacy-policy

🔒 Segurança

Adotamos boas práticas de desenvolvimento para garantir a segurança do aplicativo:

  • Comunicação com a API realizada via HTTPS
  • Chaves de API protegidas e não expostas no código-fonte
  • Nenhum dado sensível trafega pela rede

👶 Crianças

O CineScope não é direcionado a crianças menores de 13 anos e não coleta intencionalmente informações de crianças. O conteúdo exibido é proveniente de uma base de dados pública de filmes.

🔄 Alterações nesta Política

Esta política pode ser atualizada periodicamente. Quando isso ocorrer, a data de "última atualização" no topo desta página será modificada.

Recomendamos revisar esta página ocasionalmente para se manter informado sobre como protegemos suas informações.
